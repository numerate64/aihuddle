# Contributing to AI Huddle

AI Huddle is intended to grow with its community. You do not need to write code to contribute.

## Ways to help

- Suggest a future discussion topic
- Volunteer to frame or facilitate a conversation
- Share a real-world lesson, question, or useful resource
- Improve the site or fix an accessibility issue

Use the repository issue forms to raise your hand or suggest a topic. For site changes, open an issue before a large pull request so the direction can be discussed first.

## Content guidelines

Contributions should be practical, respectful, vendor-neutral, and useful across experience levels. Product experience is welcome; disguised sales pitches are not.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
